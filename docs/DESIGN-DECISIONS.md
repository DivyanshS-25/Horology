# HOROLOGY — Design Decisions & Reference Analysis

## 1. Reference Image Analysis
The reference board (`reference/midnight-navy-reference.png`) outlines the complete 15-panel user flow and aesthetic identity for **HOROLOGY: Beyond Time. Beyond Ordinary.**

### Color Palette Sampling
- **Canvas Base Background:** `#07111F` (Deep Midnight Obsidian)
- **Secondary Surface / Header / Drawer:** `#0B192A` (Abyssal Navy)
- **Card Background:** `#102238` (Midnight Navy Container)
- **Elevated / Hover Card:** `#162E4D` (Subtle Luminous Tint)
- **Primary Accent:** `#8DB8E8` (Horological Platinum Ice)
- **Secondary Accent:** `#B9CDE2` (Muted Steel Frost)
- **Accent Glow / Tint:** `rgba(141, 184, 232, 0.12)`
- **Hairline Borders:** `#1E324A` and `#263A50`
- **Text Primary:** `#F1F4F8` (Pristine Frosted White)
- **Text Secondary:** `#A6B2C2` (Refined Slate Gray)
- **Text Subtle:** `#6B7F96` (Muted Dark Slate)
- **Status Verified:** `#10B981` / `#2DD4BF` (Precision Emerald / Teal)
- **Status Demonstration:** `#F59E0B` (Amber Horological Distinction)

### Typography Rules
- **Headings & Brand Title:** Editorial Serif (`Cormorant Garamond`, `Playfair Display`, serif) with elegant letter-spacing, uppercase tracking on section overlines.
- **Body & UI Elements:** Precision Modern Sans (`Inter`, `Manrope`, sans-serif) for high legibility, clean forms, and tactile UI elements.
- **Technical & Calibration Metrics:** Monospaced Numbers (`JetBrains Mono`, `IBM Plex Mono`, monospace) for amplitude (`268°`), daily rate (`+3 s/d`), beat error (`0.1 ms`), case diameters, reference numbers, and currency values.

### Aesthetic Principles
1. **Low-key Luxury & Restraint:** No loud neons, no harsh gradients. Depth is created through midnight tones, hairline borders (1px solid), and radial gradients centered behind hero timepieces.
2. **Hairline Precision:** Crisp 1px borders, subtle 2px–4px border radii, fine dividers, and deliberate micro-typography.
3. **Honesty & Integrity Layer:** Clear distinction between verified physical watches and demonstration sample records. Unverified technical readings explicitly show status badges rather than fabricated data.
4. **Physical Craft Visuals:** Mechanical movements, timegrapher acoustics, balance wheel dynamics, and macro loupe inspections.
